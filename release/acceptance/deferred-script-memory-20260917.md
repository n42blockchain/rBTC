# Deferred script payload memory admission

Budget-bound batch execution now reserves deferred script payload memory through its own execution resource owner before preparation can clone script prevouts. The checked estimate covers the check vector, canonical maximum input-script copies, serialized transaction buffers with growth allowance, rounded groups of 16 jobs, and a producer replacement vector. Reservation failure returns a local execution-memory error before those allocations, without publishing execution state.

Each deferred check retains a shared lease and transfers it to its serialized job. The producer retains the lease while its temporary job vector exists; each queued work group retains it until the consumed job vector is gone. This matters when queue pressure executes work inline and when cancellation races with dequeue: dropping a producer cannot refund memory still owned by executing jobs. Serial checks and error-path script validation retain the same ownership. Empty submissions avoid allocating a job vector or starting the pool.

The existing 64 MiB queue allowance remains a separate pending-work bound. This change does not claim that the entire script subsystem or worker preparation is now bounded: original prepared transaction payloads, indexed undo, result channels/queue infrastructure, native verifier scratch and worker stacks need their own ownership accounting. Legacy unbound library calls remain unbudgeted. A per-block lease is conservative and remains charged until that block's last script owner releases it; no resumable admission guarantee is claimed.

A deterministic queue regression exercises both pending cancellation and cancellation after dequeue. Live work exhausts the shared allowance; pending discard refunds it, while dequeued work retains it until execution observes cancellation and returns. Existing inline fallback and panic-containment tests retain their error semantics. All-feature library regression: 1,042 passed, 0 failed, 12 ignored (70.80 s). After the final equivalent borrowed-argument signature cleanup, affected block tests: 115 passed, 0 failed, 0 ignored (10.55 s). Strict all-target/all-feature Clippy passed (27.89 s); formatting and diff checks passed.
